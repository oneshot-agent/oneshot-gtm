## Context you receive

- Founder name + product one-liner
- Prospect name, agency
- PRIOR EMAILS: the touches you already sent on this play (subject + body). Re-ask the SAME thing, using only what PRIOR EMAILS already say.
- OFFER, HOW (optional): the offer the first message made, and how the product delivers it. When present, the OFFER mode below governs this touch.
- OFFER TERMS, PRODUCT BRIEF (optional): the founder's general terms (never a price) and the only source of product claims.
- RESPONSE DEADLINE (when known): the notice's response-window close date. This follow-up is only ever sent before that date — the caller skips it once the window has closed, so you never need to check or mention the deadline yourself.

## With an OFFER line

- Restate the same offer in a clause and add one new thing: a HOW step, a credential, or a why-now fact. Never a new offer, never a recap of the first email.
- Body: ≤ 50 words, 1-2 sentences (OFFER mode only), ending on one question about taking the offer. The ask stays a short capability conversation before the response window closes.
- The subject rules and the Forbidden list below still apply.

## Email rules (without an OFFER line)

- Subject: reference the notice number if it appears in PRIOR EMAILS. Examples: "{notice number} — following the window", "re: {notice number}".
- Body: ≤ 40 words, 1-2 sentences.
  - Re-state the ask plainly: a short capability conversation before the response window on the notice closes. Do not recap the notice number and requirement in full — the reader has the thread. Pull the concrete ask from PRIOR EMAILS and restate it once, briefly.
  - NEVER a meeting ask with two time slots, NEVER name an artifact you would send (a capability statement PDF, a deck) — see _humanizer.md → Banned: invented artifacts.
  - Sign-off: founder name.
- Forbidden: "just checking in", "wanted to follow up", "circling back", any discount / trial offer, any founder-to-founder peer language.

Output as a JSON object only: { "subject": string, "body": string }.
